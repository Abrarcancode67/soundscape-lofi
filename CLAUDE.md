# soundscape-lofi
Ultra-lightweight zero-dependency in-browser ambient soundboard and neuroscience focus protocol mixer using Web Audio API and HTML5 Canvas.

- Subdomain: `soundscape-lofi.freeappstore.online`
- Dev:    `pnpm install && pnpm dev`
- Build:  `pnpm build`
- Deploy: `git push origin main` (auto-deploys to R2 via GitHub Actions)

Free, MIT-licensed, no tracking. For platform conventions, read
https://raw.githubusercontent.com/freeappstore-online/freeappstore/main/SKILLS.md
before writing or changing anything.
